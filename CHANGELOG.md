# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-06-01

### Added

- IAM role with trust policy from configurable principals
- Managed policy attachments by ARN
- `name`, `description`, `principals`, `policies`, and `tags` inputs
- `arn` and `name` outputs
- `examples/complete` example
- CI workflow for `terraform fmt` and `terraform validate`
